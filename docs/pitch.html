01 · Problem

Your camera roll is a graveyard of intentions.

We screenshot the concert we want to go to, the book a friend loved, the chart we meant to read up on. Then nothing happens. The screenshot sits there.

Turning a screenshot into an action today means retyping it, or uploading it to someone's cloud.

Cloud assistants don't work on a work laptop

  • The whole image goes to a remote server: names, emails, internal numbers and all.
  • NDAs and compliance policies often forbid sending internal material to outside services.
  • So the screenshots that matter most at work are the ones you can't send anywhere.

03 · Architecture

Two zones. One door between them.

Latent · HACK19843 / 7
Green is your laptop: Qwen2.5-VL reads the image through Ollama on loopback, the scrubber strips PII, the query builder keeps only public entities. One arrow crosses: up to three short text queries, each request at most 4 KB. The egress guard runs on your laptop, right at the boundary: it is the only module allowed to open a connection, it logs every attempt, and the request crosses only after it passes.

Egress guard · first failure blocks

  1. Air-gap on (LATENT_OFFLINE) blocks everything
  2. Allow-listed host, https, default port
  3. Body ≤ 4096 bytes (an image cannot fit)
  4. No base64-looking run of 200+ chars
  5. No PII found in any string in the body
  6. No API key in the body (headers only)

05 · Business model

Free for people. Paid for companies.

B2C  Affiliate share on the action

  • Ticket, shopping and book cards are where intent turns into a purchase.
  • Every commercial link already passes through one hook, affiliate.tag_url, where a partner tag goes.
  • Revenue only on links the user chooses to click; the app stays free.

B2B  Enterprise tier (planned)

  • On-prem model: the vision model runs on company hardware.
  • Policy controls: admins set the egress allow-list, scrubber rules and air-gap defaults.
  • Audit-log export: every outbound request, sent or blocked, for compliance review.

Latent · HACK19846 / 7
How does this scale to millions? The expensive part, the vision model, runs on each user's own machine, so our servers only carry a thin search proxy, accounts and billing; we never pay for GPUs and we never hold anyone's screenshots. The path: an installable desktop app that bundles the local runtime and picks a model that fits the user's RAM; then our own search proxy, so API keys leave the device, with no query logs and rate limits; then enterprise pilots with a self-hosted proxy or a full air-gap; then on-device mobile. Trust has to scale too: one egress point, an outbound log users can read, the leak-test eval on fake-PII screenshots, and later a third-party audit and SOC 2. Revenue: a free tier with a search cap, a Pro subscription, affiliate links that carry no user data, and per-seat enterprise. Risks: weak laptops get smaller model tiers or an OCR-only mode; against platform owners we are cross-platform, inspectable and enterprise-first; search cost is handled with caching and caps.
